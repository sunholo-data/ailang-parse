Overview

The AILANG Parse connector is a remote MCP server that lets an AI assistant parse, convert and edit documents with your AILANG Parse account. You add one URL to the assistant and sign in once in your browser. You never copy an API key.

https://docparse.ailang.sunholo.com/mcp/connect/
  • Transport: Streamable HTTP.
  • Sign-in: OAuth 2.1 with PKCE. The assistant registers itself automatically (client ID metadata documents), so there is no client ID or secret to enter: leave any OAuth client fields empty.
  • Account: you sign in with Google or GitHub. Usage through the connector counts against your plan, like any other request.

Setup

Claude Code

claude mcp add --transport http docparse https://docparse.ailang.sunholo.com/mcp/connect/

Then, inside Claude Code, run /mcp, choose docparse and select Authenticate. Your browser opens the sign-in page; when you have approved, Claude Code shows the server as connected.

Claude (claude.ai and Claude Desktop)

  1. Open Customize → Connectors (on older versions: Settings → Connectors).
  2. Click + Add, then Add custom connector.
  3. Enter a name (for example AILANG Parse) and paste the connector URL above. Leave the OAuth client ID and secret empty.
  4. Click Add, then Connect to sign in.
  5. In a conversation, use the + button → Connectors to switch it on.

On Team and Enterprise plans an organisation Owner first adds the connector under Organization settings → Connectors; members then click Connect. Free plans are limited to one custom connector. See Anthropic’s guide: Get started with custom connectors using remote MCP. A listing in Claude’s connector directory is coming; once it is live you will be able to add AILANG Parse from there without pasting the URL.

Codex

codex mcp add docparse --url https://docparse.ailang.sunholo.com/mcp/connect/
codex mcp login docparse

codex mcp login opens the sign-in page in your browser and stores the result for later sessions.

ChatGPT

ChatGPT adds custom MCP servers as plugins (formerly “apps” or “connectors”). Custom MCP servers need Developer mode, which is available on some plans only and may have to be enabled by your workspace admin.

  1. Turn on Developer mode in ChatGPT’s settings (under Apps & Connectors → Advanced on most accounts).
  2. Open Plugins in ChatGPT (chatgpt.com/plugins), select + and choose Add custom MCP server.
  3. Enter a name and description, paste the connector URL above, and choose OAuth for authentication.
  4. Review the warning, continue, and sign in when ChatGPT opens the sign-in page.
  5. In a conversation, type @ and select the plugin.

OpenAI moves these settings from time to time; their current instructions are in Connect from ChatGPT.

Other MCP clients

Any client that supports remote MCP servers over Streamable HTTP with OAuth can use the same URL.

Signing in

When the assistant first needs your account, it opens https://docparse.ailang.sunholo.com/oauth-login.html in your browser:

  1. The page shows which app is asking and where it will send you back. Check both before continuing.
  2. Sign in with Google or GitHub in the popup window.
  3. Click Allow. Nothing is granted until you do; choosing not to allow leaves the app unconnected.
  4. Your browser returns to the app, which confirms the connection.

What a connection is. The app receives an access key for your account, labelled oauth: <app host> (for example oauth: claude.ai). The key lasts 24 hours. The app renews it automatically with a refresh token valid for 30 days; each renewal replaces the old key. If the app is not used for 30 days, you sign in again.

Tools

The connector provides these tools. None of them delete or overwrite anything you own: editing returns a modified copy, and your original document is never changed.

ToolWhat it doesSign-inHints
mcpParse
Parse document		 Reads a document (Office, PDF, HTML, Markdown, email, images and more) into structured blocks, Markdown or HTML, keeping tables, headings, comments and tracked changes. Required Read-only
mcpConvert
Convert document		 Creates a document in another format (Word, PowerPoint, Excel, OpenDocument, HTML, Markdown, Quarto), either from Markdown the assistant writes or from an existing document. The result includes a private download link valid for one hour. Required Read-only
editDocument
Edit document		 Applies structured edits to an Office document and returns the edited content. The assistant can then turn it into a file with mcpConvert. Required Read-only (returns a copy)
mcpAccount
Account, quota and usage		 Shows your plan, usage this month and remaining allowance, and your keys. It can also switch request history on or off for your account. Required Changes a setting only when asked; not destructive
mcpFormats
List formats and capabilities		 Lists what AILANG Parse can read and write, how to send it a document, and the sample documents you can try. Not needed Read-only
mcpEstimate
Estimate cost and latency		 Predicts how long a document will take and whether it needs AI processing, before parsing it. Not needed Read-only
submit_feedback
Send feedback		 Sends a bug report, feature request or documentation gap to the AILANG team for human review. Not needed Sends a message; not destructive

The tool list can change as the service improves; your assistant always shows the current list and descriptions.

Using it

Ask naturally, for example “parse this contract and list the tracked changes”, “turn these notes into a PowerPoint” or “try AILANG Parse on a sample DOCX”. The assistant can give AILANG Parse a document in three ways: the file itself, a public https:// link, or one of the built-in sample documents. Created files come back with a download link that is valid for one hour.

Revoking access

  • On the dashboard: open your dashboard, go to API keys and revoke the key labelled oauth: <app host>. Access stops at once.
  • In the app: remove or disconnect the connector (Claude: Customize → Connectors; Claude Code: claude mcp remove docparse; Codex: codex mcp logout docparse; ChatGPT: remove the plugin).

Troubleshooting

After signing in, the browser shows a localhost page or “unable to connect”

Desktop and command-line apps (Claude Code, Codex) receive the sign-in on a temporary local address such as http://localhost:…. That listener only runs while the app is waiting, so keep the app open until it confirms the connection, then try again from the app. If the app runs on a different machine from your browser (for example over SSH), copy the full localhost URL from the browser’s address bar and paste it back into the app when it asks; Claude Code supports this.

The sign-in popup does not appear

Your browser is blocking popups. Allow popups for docparse.ailang.sunholo.com and click the sign-in button again.

“This sign-in request has expired or was already used”

Each sign-in request is valid for 10 minutes and can be used once. Close the tab and start the connection again from the app (Claude Code: /mcp → Authenticate; Codex: codex mcp login docparse; Claude and ChatGPT: Connect on the connector).

“Needs you to sign in again”, “not authenticated” or a 401 error

The access key expired and could not be renewed. Keys last 24 hours and are renewed only while the app is in use; refresh tokens expire after 30 days, and revoking the key on the dashboard also ends the connection. Re-authenticate from the app as above.

A tool says you have reached your plan’s limit

Your monthly allowance is used up. It resets at the start of each month. You can see your usage, and manage your account, on the dashboard, or ask the assistant to run mcpAccount.

A link cannot be fetched

Links must be publicly reachable over https://. Pages behind a login cannot be read; give the assistant the file itself instead.

The connector shows no tools, or old tools

Reconnect or refresh the connector in the app (ChatGPT: open the plugin and select Refresh; Claude Code: /mcp).

Agents without a browser

The connector URL above is for apps that can open a browser for you. Headless agents, scripts and CI jobs should use the agent endpoint https://docparse.ailang.sunholo.com/mcp/ instead, with either:

  • Device sign-in: the agent calls mcpAuth, you approve a short code in any browser, and the agent collects its key with mcpAuthPoll.
  • An API key created on the dashboard.

Details are on the MCP server page.

Privacy & support

The assistant sends AILANG Parse only the tool call: the document and options you ask it to work on, never your conversation. How connections, keys and created files are stored is described in our privacy policy; see also the terms.
