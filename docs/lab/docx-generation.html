Lab — browser-side DOCX generation

Unlinked validation page. Does generating a Word document entirely in the browser cost more than it is worth?

Drop any supported document (or use the sample). It is parsed in the browser, the blocks are handed back to AILANG's DOCX generator, and the resulting OPC parts are zipped here in JavaScript — no server, no upload.

Demo documents — these are the same files the samples API serves. DOCX is the only output format for now; the input can be anything the browser parser handles, so the non-DOCX entries exercise cross-format conversion.
