Getting Started with AILANG Parse

AILANG Parse is an open-source document parsing engine that converts office documents, PDFs, emails, and media files into a unified Block ADT (Algebraic Data Type). It runs natively, in the browser via WASM, and as a cloud API.

Why AILANG Parse? Most document parsers are format-specific black boxes. AILANG Parse gives you one structured output for 16+ formats — deterministic for office files, AI-powered for PDFs and media — with typed errors, cost metadata, and full replayability.

Quick Start

1. Install the SDK

Choose your language:

# Python
pip install ailang-parse

# JavaScript / TypeScript
npm install @sunholo/ailang-parse

# Go
go get github.com/sunholo-data/ailang-parse-go

2. Parse Your First Document

# Python example
from ailang_parse import parse

result = parse("quarterly_report.docx", output="markdown")
print(result.text)        # Markdown output
print(result.blocks)      # Structured Block ADT
print(result.metadata)    # Page count, word count, images found

Tip: For deterministic formats (DOCX, XLSX, PPTX, HTML, CSV, Markdown), no API key is needed. AI-powered formats (PDF, images, audio, video) require a Gemini or Anthropic API key.

The Block ADT

Every parsed document becomes a list of Blocks. There are 9 block variants:

Block Type Description Key Fields Example Source
Text Paragraph or body text content, style Word paragraphs, email body
Heading Section heading (levels 1–6) content, level HTML <h1>–<h6>, DOCX styles
Table Tabular data with rows and cells rows, headers, merged_cells Excel sheets, HTML tables
Image Embedded image with optional caption path, alt_text, mime_type DOCX images, PPTX shapes
Audio Audio content with transcription path, transcript, duration MP3 files, embedded audio
Video Video content with description path, description, duration MP4 files, embedded video
List Ordered or unordered list items, ordered, nested Bullet points, numbered steps
Section Logical grouping of blocks title, children EPUB chapters, PPTX slides
Change Tracked revision (insert/delete) content, author, type, date DOCX track changes

Supported Formats

Deterministic Parsers No AI needed

These parsers produce identical output for the same input, every time:

  1. DOCX — Word documents with full fidelity
    • Tables with merged cells and styles
    • Track changes (insertions, deletions, moves)
    • Comments with author attribution
    • Headers, footers, and footnotes
    • Embedded images (PNG, JPEG, EMF, WMF)
  2. PPTX — PowerPoint presentations
    • Slide content with speaker notes
    • Tables and shapes
    • Master slide layouts
  3. XLSX — Excel spreadsheets
    • Multiple sheets as sections
    • Formulas (cached values)
    • Merged cells and number formats
  4. HTML — Web pages and email HTML
  5. CSV / TSV — Delimited data files
  6. Markdown — Documentation and notes
  7. EPUB — E-books with chapter structure
  8. ODT / ODP / ODS — OpenDocument formats
  9. EML / MBOX — Email messages with attachments

AI-Powered Parsers API key required

These use multimodal AI (Gemini or Claude) for extraction:

  • PDF — Scanned documents, complex layouts, equations
  • Images — Photos, diagrams, screenshots, handwriting
  • Audio — Speech transcription, speaker identification
  • Video — Visual + audio understanding, slide extraction

Architecture

The processing pipeline has four stages:

1. Format Detection
Identifies the input format by MIME type and file extension. ZIP-based formats (DOCX, PPTX, XLSX, EPUB, ODT) are detected by inspecting archive contents.
2. Parser Selection
Routes to the appropriate parser module. Deterministic parsers handle structured formats; AI parsers handle visual/audio content.
3. Block Extraction
The parser converts format-specific structures (XML elements, table cells, slide shapes) into the universal Block ADT.
4. Output Formatting
Blocks are serialized to the requested output format: JSON (structured), Markdown (human-readable), HTML (web-ready), or A2UI (agent-friendly).

Output Formats

Format Content-Type Best For
JSON (blocks) application/json Programmatic access, pipelines, indexing
Markdown text/markdown LLM context, documentation, human reading
HTML text/html Web display, email rendering
A2UI application/json Agent-to-UI protocol, MCP tools, rich rendering

API Usage

The cloud API at docparse.ailang.sunholo.com provides all parsing capabilities behind a simple REST interface:

curl -X POST https://docparse.ailang.sunholo.com/api/v1/parse \
  -H "Authorization: Bearer dp_your_api_key" \
  -F "file=@report.docx" \
  -F "output=markdown"

Key Endpoints

  1. GET /api/v1/capabilities — Machine-readable capability manifest
  2. GET /api/v1/formats — Supported input formats
  3. GET /api/v1/samples — Sample files for testing
  4. POST /api/v1/parse — Parse a document
  5. POST /api/v1/estimate — Cost and latency estimation
