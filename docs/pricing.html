Questions & answers

When should I use AILANG Parse?

Use AILANG Parse when your AI system ingests Office documents (DOCX, PPTX, XLSX, ODT) and you need structured, accurate output. We read Office XML directly — no PDF conversion, no OCR, no information loss. Track changes, merged table cells, comments, and formatting are all preserved. If your RAG pipeline or agent system processes business documents, this is built for you.

When should I NOT use AILANG Parse?

If you only need to parse scanned PDFs or handwritten documents, a dedicated OCR service (like Google Document AI or Amazon Textract) may be more appropriate. Our AI parsing handles PDFs, but our structural advantage is in Office formats where we bypass the PDF-then-OCR pipeline entirely. For pure image/scan workloads, we add an AI layer but don't offer a unique cost or quality advantage.

Why is it so much cheaper than competitors?

Competitors charge per page because they convert your DOCX to PDF, render it as images, then run OCR or vision models to recover the text. That's expensive compute for every page. We read Office XML directly — the structured data is already there. A 200-page DOCX takes ~50ms to parse deterministically on a single Cloud Run instance. No AI model needed, no per-page cost. One request = one document, regardless of page count.

What are "AI parses" vs regular requests?

Regular requests use our deterministic parser — fast, cheap, and reliable for Office formats (DOCX, PPTX, XLSX, ODT, ODP, ODS, CSV, Markdown, HTML, EPUB). AI parses invoke a vision model (Gemini 2.5 Flash) for formats that need it: PDFs, images, audio, and video. AI parses are metered separately because they cost more (~€0.003/parse vs ~€0.000002/deterministic request).

What does "daily rate limit" mean?

The daily rate limit is a coarse burst-protection cap — the maximum number of requests you can make in a single calendar day. It prevents accidental runaway scripts from exhausting your monthly quota in one burst. For most users, the monthly limit is the binding constraint. At the Free tier, 500/day × 30 days = 15,000, so you can use your full 10,000 monthly quota comfortably without hitting the daily cap.

Do you support the Unstructured API format?

Yes. We provide a drop-in compatible endpoint at /general/v0/general that accepts the same multipart request format as the Unstructured API. If you're migrating from Unstructured, you can change the base URL and get higher accuracy at a fraction of the cost. All tiers include this endpoint.

What output formats are available?

All tiers: JSON (Block ADT), Markdown, plain text, and HTML. Pro and above: Quarto (.qmd), A2UI (agent-to-UI protocol), and DOCX/PPTX document generation (round-trip: parse a document, modify the blocks, generate a new document). The JSON Block ADT has 9 structured variants — Text, Heading, Table, Image, Audio, Video, List, Section, and Change — preserving the full semantic structure of the source document.

How does request replay work?

Available on Pro and above. Every parse request is logged with its input, output, and metadata. You can replay any past request to reproduce the exact same output — useful for debugging agent pipelines, regression testing, and auditing. History is retained for 180 days (Pro) or 365 days (Business).

Can I self-host AILANG Parse?

Yes. AILANG Parse can run locally or on your own infrastructure. See Run Locally for Docker and CLI options. The free tier is generous enough for most evaluation and development use cases, and self-hosting gives you unlimited deterministic parsing with no API key required.
