    Run It Yourself

    1. Download the filing. SEC asks scripts to say who they are, so put your name and email in the -A (User-Agent) value. 
      curl -sL -A "Your Name you@example.com" -o anthropicpbc-sx1.htm \
  https://www.sec.gov/Archives/edgar/data/2130357/000162828026067168/anthropicpbc-sx1.htm
    2. Parse it. This writes anthropicpbc-sx1.htm.json (the structure) and anthropicpbc-sx1.htm.md (Markdown to give a model). 
      docparse anthropicpbc-sx1.htm
    3. Query the JSON. For example, the outline, every risk factor with its page, or one row of a table: 
      jq -r '.document.blocks[]
  | select(.type == "heading" and .level <= 2)
  | ("  " * (.level - 1)) + .text' anthropicpbc-sx1.htm.json
      jq -r 'foreach .document.blocks[] as $b ({page: "", h1: ""};
    if $b.type == "section" and $b.kind == "page-break" then .page = ($b.name // "")
    elif $b.type == "heading" and $b.level == 1 then .h1 = $b.text
    else . end;
    select(.h1 == "Risk Factors" and $b.type == "heading" and $b.level == 4)
    | "p.\(.page)  \($b.text)")' anthropicpbc-sx1.htm.json
      jq -c '.document.blocks as $b
  | ($b | map(.text) | index("Consolidated Statements of Operations Data")) as $i
  | $b[$i:] | map(select(.type == "table")) | .[0].rows[1]' anthropicpbc-sx1.htm.json
# ["Revenue","$41","$386","$4,585","$1,163","$16,286"]
