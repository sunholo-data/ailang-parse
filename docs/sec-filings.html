    Outline-First Reading

    Ask a model about an S-1 by pasting the whole filing and you spend hundreds of thousands of tokens on every question. Give it the outline first and it can choose what to read. With structured blocks, an agent can work in three steps:

    1. Read the outline. All the headings, with page numbers.
    2. Pick the sections the question needs: "What does the company say about compute supply?" points to a handful of risk factors and one sub-section of MD&A.
    3. Fetch only those blocks, using the block index on each heading, and cite the page each passage came from.

    Token counts are estimates (words × 1.3).

    What Still Needs AI

    Some of the filing is only in pictures. The founders' letter that opens the prospectus is eight page images, and the customer case studies are images too. They come through as image blocks in place, so you can see exactly what's there and send just those pages to a model.

    Run docparse with --describe (opt-in, uses AI) and keep the images next to the .htm to have each one described.

    Try It

    EDGAR asks for a User-Agent with a contact address. You get a .json file with the structure and a .md file for a model to read.

    curl -sL -A "Your Name you@example.com" -o anthropicpbc-sx1.htm \
  https://www.sec.gov/Archives/edgar/data/2130357/000162828026067168/anthropicpbc-sx1.htm

docparse anthropicpbc-sx1.htm      # writes anthropicpbc-sx1.htm.json and .md
    jq -r '.document.blocks[]
  | select(.type == "heading" and .level <= 2)
  | ("  " * (.level - 1)) + .text' anthropicpbc-sx1.htm.json
    # Carry the page and the level-1 section along, keep the risk-factor titles
jq -r 'foreach .document.blocks[] as $b ({page: "", h1: ""};
    if $b.type == "section" and $b.kind == "page-break" then .page = ($b.name // "")
    elif $b.type == "heading" and $b.level == 1 then .h1 = $b.text
    else . end;
    select(.h1 == "Risk Factors" and $b.type == "heading" and $b.level == 4)
    | "p.\(.page)  \($b.text)")' anthropicpbc-sx1.htm.json
    jq -c '.document.blocks as $b
  | ($b | map(.text) | index("Consolidated Statements of Operations Data")) as $i
  | $b[$i:] | map(select(.type == "table")) | .[0].rows[1]' anthropicpbc-sx1.htm.json
# ["Revenue","$41","$386","$4,585","$1,163","$16,286"]
