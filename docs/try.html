Supported Formats

AILANG Parse uses AILANG modules running in WebAssembly to parse documents entirely in your browser. Office documents are handled by pure std/xml functions; PDFs, images, and media use AILANG's AI effect with Gemini.

Pure Office Documents

DOCX, PPTX, and XLSX are ZIP+XML archives. Parsed deterministically via AILANG's std/xml — no AI needed.

Frequently Asked Questions

Can I parse DOCX files in the browser without a server?

Yes. AILANG Parse compiles to WebAssembly and runs entirely in your browser. Drop a DOCX, PPTX, or XLSX file and it parses locally — your file never leaves your machine. No Python, no server, no upload. The WASM module parses documents in milliseconds.

Does AILANG Parse require Python or any runtime dependencies?

No. AILANG Parse is written in AILANG (which compiles to Go) and has zero runtime dependencies for Office format parsing. It runs as a standalone binary, Docker container, WebAssembly module, or via the REST API. There is no Python, Java, or Node.js requirement.

How does browser-based document parsing work with WebAssembly?

The AILANG Parse WASM module runs in a Web Worker. When you drop a file, JavaScript reads it as bytes, passes the buffer to the WASM module, which unzips the Office XML and extracts structured blocks. The output is returned to the main thread. Everything runs client-side with no network calls.

Is the browser WASM parser the same as the server API?

Yes, it is the same parsing engine compiled to a different target. The WASM module and the server binary both use the same AILANG parser modules with the same 63 Z3-verified contracts. Output is identical for Office formats. The only difference is that the WASM module does not include AI-powered PDF parsing, which requires a server-side model.
